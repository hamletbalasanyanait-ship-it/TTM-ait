# business

Business page (`/business`) built from https://www.telecomarmenia.am/hy/b2b/

- `hooks/useReveal.js` scroll-reveal hook (IntersectionObserver)
- `data/` tariffs, services and virtual PBX content
- `Icons.jsx` inline SVG icons
- Header and Footer come from `App.jsx` (shared), not from this folder
- All CSS classes start with `biz-` to avoid clashes with other pages
